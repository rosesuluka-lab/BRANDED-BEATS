## Overview

Branded Beats is a creative coding project that explores the relationship between music, branding and digital creativity. Using Python in TunePad, the project creates three original musical compositions inspired by three industries: luxury, beauty, and streetwear. Each composition explores how sound, rhythm and musical elements can communicate a distinct brand identity and atmosphere. The project demonstrates how coding can be used as a creative tool to translate visual and cultural concepts into music.

## Three Compositions

### 1. Luxury

This composition explores the sound and atmosphere associated with luxury branding, aiming to communicate a sense of sophistication and elegance through music. It uses musical elements to translate the luxury aesthetic into an original beat.

Access the composition: https://tunepad.com/project/134632
### 2. Beauty

This composition explores the beauty industry's identity through an original musical arrangement, focusing on creating a sound that reflects its creative and expressive nature. It demonstrates how music can be used to communicate the atmosphere of a beauty brand.

Access the composition: https://tunepad.com/project/135212

### 3. Streetwear

This composition draws inspiration from streetwear culture, translating its bold and contemporary identity into an original beat. It explores how rhythm and sound can communicate a different brand personality compared with luxury and beauty.

Access the composition: https://tunepad.com/project/134629
